## 文档维护约定

- 本入口只维护当前状态、阶段导航和阅读路径，不记录详细实施过程。
- 每个阶段使用 `stages/NN-topic.md`，阶段结束后冻结；后续勘误可以修改，但不继续追加新阶段内容。
- 每项有独立问题、代码、配置、数据库或行为变化的改动，在 `changes/` 下建立一份详情，并在[改动索引](changes/README.md)登记。
- 小型文档整理可以只记入索引；需要复现、迁移或回滚的改动必须有详情页。
- 详情页至少记录问题、范围、关键文件、验证、数据影响、Git 提交和回滚方式；可从[改动记录模板](changes/TEMPLATE.md)开始。
- 原始调研材料、API 密钥、中间件卷和本地备份不进入 Git。文档只记录获取或恢复方法，不复制秘密值。
- Git 提交是代码和文档的事实依据；文档中的状态与当前 checkout 冲突时，先核对分支、HEAD 和工作区，再更新文档。
