# 工业文档 RAG 项目：简历深挖问题清单

本清单以当前 [流程笔记](../flow-notes/01-login-and-access.md) 01—09 为项目提问依据。问题中的简历数字是待解释的历史实验结果，不代表本次重新运行或生产收益。涉及未来设计的题目应明确用“如果扩展，我会……”作答；个人贡献应由本人按实际分工补充，不能把开源框架全部算作个人实现。

P0 为简历直接相关、必须能独立讲清的问题；P1 为常见技术追问；P2 为进阶与扩展。建议每题先用 30—60 秒回答主问题，再逐层展开追问。回答优先解释“输入是什么、怎么处理、输出是什么、为什么这样做”，首次出现英文术语时附中文名称。
