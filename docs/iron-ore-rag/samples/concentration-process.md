# 浓度检测

## 检测内容

| 检测内容 | 概念 | 核心作用 |
| --- | --- | --- |
| 浓度 | 铁矿石检测里的浓度是指矿浆浓度，是矿浆里干铁矿粉的重量，占整份矿浆总重量的比例，用百分比表示。（比例工厂会根据自家原矿硬度、磨矿设备、选别工艺微调，无固定标准值）。 | 1. 控制磨矿分级效果：浓度偏高加水稀释，偏低减少补水，避免影响分级精度。2. 快速判断生产是否正常，及时调整。3. 精准浓度测定，用于结算、品控。 |

## 生产现场：在线检测

- 检测类型：现场检测。
- 检测目的：为了实时指导生产，磨机、浮选机一直在运转；浓度变化会影响产量、品位和回收率。工人需要在几分钟内知道结果并调整水量或矿量，允许合理误差但必须快速。
- 工具：在线浓度计。
- 物料形态：矿浆。
- 操作步骤：
  1. 在对应工段的核心矿浆输送管道上安装在线浓度计，确保设备正常运行且数据可传输。
  2. 读取并留存数据。

## 生产现场：浓度壶称重法

- 检测工序：人工辅助检测。
- 工具：采样桶、1 L 浓度壶、抹布、现场浓度表、笔或记录单。
- 物料形态：矿浆。
- 关键参数和公式：浓度壶空重预先标注；矿浆净重 = 总重 - 空壶重；根据现场浓度表确认浓度。
- 操作步骤：
  1. 确认空壶重量：提前称量 1 L 浓度壶空重，用马克笔标注于壶身，无需重复称重。
  2. 取样装壶：用采样桶舀取矿浆，缓慢倒入浓度壶，确保液面与壶身刻度线齐平。
  3. 称重计算净重：擦干壶外壁水分，称取浓度壶与矿浆总重，减去空壶重得到矿浆净重。
  4. 查表记录浓度：对照现场浓度表，根据矿浆净重找到对应浓度值，记录并用于调整。

## 生产现场：实验室烘干称重法

- 检测类型：实验室检测。
- 检测目的：快速判断生产是否正常，及时调整；该方法用于观察趋势、调整参数和保障运行，检测次数较少，精度要求低于中心实验室。
- 工具：采样桶、精密电子天平（0.01 g 精度）、烘干炉、木质坩埚夹、笔或记录单。
- 物料形态：烘干前为湿矿浆，烘干后为干矿样。
- 关键参数和公式：矿浆无固定采样量，足量即可；湿重为矿浆与采样桶总重（采样桶空重已知）；干重为干矿样与采样桶总重；浓度 = 干矿样质量 / 湿矿浆质量 × 100%。
- 操作步骤：
  1. 现场取样：采集矿浆至采样桶，确保样品具有代表性并避免混入杂质。
  2. 称湿重：确认采样桶空重，称取矿浆与采样桶总湿重并记录。
  3. 烘干处理：将盛有矿浆的采样桶放入烘干炉，烘干至矿浆完全干燥。
  4. 称干重：冷却至室温后，称取干矿样与采样桶总干重。
  5. 计算浓度：按“干矿样质量 / 湿矿浆质量 × 100%”计算并记录结果。

## 中心实验室：烘干称重法

- 检测目的：精准测定浓度，用于结算和品控。
- 工具：采样桶、精密电子天平（0.01 g 精度）、电热板、坩埚夹、笔或记录单。
- 物料形态：烘干前为湿矿浆，烘干后为干矿样。
- 关键参数和公式：烘干温度为 105±5 ℃；浓度 = 干矿样质量 / 湿矿浆质量 × 100%。
- 操作步骤：
  1. 现场取样：采集矿浆至采样桶，确保样品具有代表性并避免混入杂质。
  2. 称湿重：确认采样桶空重，称取矿浆与采样桶总湿重并记录。
  3. 烘干处理：将盛有矿浆的采样桶放至电热板或智能恒温鼓风干燥箱，烘干至完全干燥，温度为 105±5 ℃。
  4. 称干重：冷却至室温后，称取干矿样与采样桶总干重。
  5. 计算浓度：按“干矿样质量 / 湿矿浆质量 × 100%”计算并记录结果。

## 差异化总结

1. 现场浓度壶对比浓度表的方法属于快速估算方式，受人工操作、设备精度和环境波动影响较大，准确度相对较低。浓度表采用固定理论值，无法随现场矿浆密度、成分和温度实时变化，与实际工况可能存在偏差。
2. 现场实验室整体精度低于中心实验室，主要原因是人员操作要求、样品处理方式、执行标准和环境条件不同。现场以快速指导生产为目标，允许合理误差；中心实验室以精准数据、结算仲裁为目标，执行更严格的标准，因此精度更高。
