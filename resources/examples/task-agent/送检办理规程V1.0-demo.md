# 样品送检办理示例规程 V1.0-demo

本文为软件功能演示构造的资料，仅定义示例送检登记流程，不是企业规程、检测方法或设备操作指令。

## 适用范围

适用于本地示例业务中的水分检测（MOISTURE）样品送检登记。系统负责工位预约和送检记录创建，实际搬运、检测和结果判定由线下人员负责。

## 送检前资料

送检前，操作员需要核对样品标签并确认交接资料齐全。标签尚未核对或交接资料不齐全时，应等待操作员补充，不能直接办理预约。

## 工位选择

水分检测样品应选择支持 MOISTURE 检测项目的工位。工位必须处于可用状态，且没有其他任务预约。仅支持 CHEMICAL 的工位不能用于水分检测送检登记。

原定工位不可用时，可重新查询其他支持相同检测项目的可用工位；没有可用工位时，等待操作员安排。

## 确认与登记

系统应在草稿中展示样品、目标工位及办理要求的文档依据。操作员确认后，再次检查样品资料和工位可用性，完成预约和送检记录创建。重复确认同一任务应返回同一份送检记录。

预约完成表示送检办理已完成，不表示样品已经搬运到位，也不表示实际检测已完成。
